# 关系规范化-2
---
核心问题，给定一个关系模式，如何判断该关系模式是第几范式？

- 首先要找出所有候选码
- 然后判断非主属性对候选码的部分依赖（2NF）和传递依赖（3NF）
- 判断所有的函数依赖是否都是依赖于码（BCNF）
- 多值依赖(4NF)和连接依赖(5NF)需要对表进行各种可能的拆分和再连接，比较难判断。

## 逻辑蕴含

关系模式 $U, F$, $F$是其函数依赖集 $X, Y \subseteq U$。如果从 $F$ 的函数依赖能够推出 $X \to Y$，则称 $F$ 逻辑蕴涵 $X \to Y$，记作 $F|X \to Y$。被 $F$ 所逻辑蕴涵的函数依赖的全体所构成的集合称作 $F$ 的闭包，记作 $F^+ = (X \to Y | F | X \to Y)$。

## Armstrong公理系统

1. 自反律(reflexivity)：若 $Y \subseteq X$，则 $X \to Y$
2. 增广律(augmentation)：若 $X \to Y$，则 $XZ \to YZ$
3. 传递律(transitivity)：若 $X \to Y$, $Y \to Z$，则 $X \to Z$

Armstrong公理系统具有正确性和完备性，即：

- 用Armstrong公理从 $F$ 中导出的函数依赖为 $F$ 所蕴涵（正确性）
- $F$ 所蕴涵的函数依赖都由Armstrong公理从 $F$ 中导出（完备性）

## Armstrong公理系统导出的推理规则

1. 合并律(union rule)：若 $X \to Y$, $X \to Z$，则 $X \to YZ$
2. 分解律(decomposition rule)：若 $X \to YZ$，则 $X \to Y$, $X \to Z$
3. 伪传递律(pseudotransitivity rule)：若 $X \to Y$, $WY \to Z$，则 $WX \to Z$

## 闭包计算

设 $F$ 为属性集 $U$ 上的一组函数依赖, $X \subseteq U$。 $X_F^+ = \{A|X \to A能由F根据Armstrong公理导出\}$。 称 $X_F^+$ 为属性集 $X$ 关于函数依赖集的闭包。

- 闭包具有封闭性: $(X^+)^{+} = X^+$
  - 证明: $\forall A \in (X^+)^{+} \Rightarrow X^+ \to A$, so $X \to X^+ \Rightarrow X \to A \Leftrightarrow A \in X^+ \Rightarrow (X^+)^{+} \subseteq X^+$
  - $X \to Y$ 能由Armstrong公理导出 $\Leftrightarrow Y \subseteq X_F^+$

### 算法：求属性集 $X$ 关于函数依赖集的闭包

1. 先把 $X$ 自身加入到 $X_F^+$ 中（自反律）。
2. 对于每一个函数依赖 $A \to B$，若 $A \subseteq X_F^+$，则 $X_F^+ = X_F^+ \cup B$。

## 候选码计算

通过闭包计算，我们已经可以判断一组属性是不是候选码了（闭包包含了所有属性）。但是此时我们需要尝试所有可能的属性组合，搜索空间太大，因此我们需要对属性进行一些区分来缩小搜索空间。

### 属性集派生

设 $F$ 为函数依赖
- 左部属性，只出现在右边的属性
- 右部属性，只出现在右边的属性
- 双部属性，出现在右边的属性
- 外部属性，不出现在中的属性
- 左部属性一定出现在任何候选码中
- 右部属性一定出现在任何候选码中
- 外部属性一定出现在任何候选码中

直到属性派生之后，我们只需要尝试：左部属性+（双部属性的所有可能组合）即可。

### 算法

1. 求一个候选码：
  1. 先令候选码 K 为全体属性。
  2. 对于 K 中每一个属性（A），尝试去掉该属性，如果去掉该属性后仍然是候选码（求闭包等于全体属性），则令 K = K - A。
  3. 重复步骤2，直到 K 为不再变化。

2. 求所有候选码：
  1. 先求一个候选码 K。
  2. K 必然由左部属性和双部属性组成。现在尝试替换双部属性中的一个属性（A），得到新的候选码 K'。
  3. 对于每一个 F: X → Y, 如果 A ∈ Y，则 K' = (K - A) ∪ X。

## 范式判定

当求出所有候选码之后，可直接进行 2NF 和 3NF 的判定：

- 2NF: 对于 F: K → A, 其中 K 是候选码，不妨设为 K=BC，分别求 B 的闭包，C 的闭包，如果任何一个闭包包含了 A，则说明 B → A 或者 C → A，即存在对主码的部分依赖，不是 2NF。
- 3NF: 一个特例是，对于所有非主属性（设为 C），如果函数依赖(AB → C)中决定该属性的属性集(AB)不是候选码，则存在传递依赖(K → AB → C)，不是 3NF。

## 函数依赖的等价和覆盖

对于函数依赖集 F, G, 若 $F^+ = G^+$，则称 F 与 G 等价

- 如何判定两个函数依赖集等价？
    - 定理: $F^+ = G^+ \Longleftrightarrow F \subseteq G^+, G \subseteq F^+$
- 如何求函数依赖集(F)的最小覆盖(F_min)?
    1. 单属性化：逐个检查中各函数依赖 $FD_i$ : X → Y。若 Y = A1A2 ... AK，则用 $X\rightarrow Ai$ 代替 Y
    2. 无冗余化：逐个检查中各函数依赖 X → A。令 G = F - (X → A)，若 $A ∈ X_G^+$，则从 F 中去掉该函数依赖
    3. 既约化：逐个检查中各函数依赖数 X → A。设 X = B1 ... Bm，逐个考查时，若 $A ∈ (X - B_i)_F^+$ 则以 $(X - B_i)$ 取代 X。
    4. 既约化一般要在无冗余化之前进行，否则既约化之后可能会再次出现冗余的函数依赖。

## 函数依赖和多值依赖的推理规则

- 自反律：若 Y ⊆ X，则 X → Y
- 增广律：若 X → Y，则 X → YZ
- 传递律：若 X → Y，Y → Z，则 X → Z
- 复制律：若 X → Y，则 X → Y
- 补充律：若 X → Y，则 X → R - X - Y
- 多值增广律：若 X → Y，Z ⊆ R，W ⊆ Z，则 X → YW
- 多值传递律：若 X → Y，Y → Z，则 X → Z - Y
- 联合律：若 X → Y，Z ⊆ Y，且存在 W，使得 W ⊆ R，W∩Y = 0，W → Z，则 X → Z
