# 关系演算

---
## 元组关系演算

### 定义

形式化定义:

```math
{t∣P(t)}
```

表⽰所有使谓词 P 为真的元组集合。其中

- P 是公式,由原⼦公式和运算符组成
- t 是元组变量,如果元组变量前有全称或者存在量词,则称其为约束变量,否则称为⾃由变量

### 原⼦公式

- $s\in R$ : s 是关系 R 的⼀个元组
- $s[X]\theta c$ :分量 $s[X]$ 与常量 $c$ 之间满⾜⽐较关系 $\theta$
- $s[x]\theta s[Y]$ :分量 $s[X]$ 与分量 $s[Y]$ 之间满⾜⽐较关系 $\theta$

### 公式的递归定义

- 原⼦公式是公式
- 若 P 是公式,则 也 $\lnot P$ 是公式
- 若 P 和 Q 是公式,则 $(P\land Q), (P\lor Q), (P\Rightarrow Q)$ 也是公式
- 若 P 是公式, R 是关系,则 $\exists t\in R(P(t)), \forall t\in R(P(t))$ 也是公式

### 关系演算表达式的安全性

引⼊公式 的域的概念,⽤ dom(P) 表⽰, dom(P) = 显⽰出现在 P 中的值 + 在 P 中出现的关系的元组中出现的值(不必是最⼩集)。

如果出现在表达式 $\{t|P(t)\}$ 结果中的所有值均来⾃ dom(P), 则称 $\{t|P(t)\}$ 为安全的。

## 域关系演算

### 定义

- $\{\langle x_1, x_2, \cdots, x_n \rangle | P(x_1, x_2, \cdots, x_n) \}$
- 其中 $x_i$ 表⽰域变量, P 是原⼦构成的公式

### 原⼦公式

- $\langle x_1, x_2, \cdots, x_n \rangle \in R$: $x_i$ 是域变量或域常量
- $x\theta c$ : 域变量 x 与常量 c 之间满⾜⽐较关系 $\theta$
- $x\theta y$ : 域变量 x 与 y 之间满⾜⽐较关系 $\theta$
