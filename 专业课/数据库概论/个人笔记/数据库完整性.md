# 数据库完整性
---

## 约束的对象级别

1. 列级约束：列值范围，如sno要求是8位整数，首位是0或1  
2. 行级约束：同一行各列之间，如飞行员的星级评定取决于其飞行里程  
3. 表级约束：行间、表上、表间，如 unique 约束（行间）

## 约束类型

- primary key  
- foreign key  
- unique  
- default  
- not null  
- check  

## foreign key

- 基本关系：主码所在的关系；依赖关系：外码所在的关系  
- 外码约束既要监视依赖关系上的修改操作，又要监视基本关系上的删除操作  
- 三种定义外码方式：

    - RESTRICT: 只有当依赖关系中没有一个外码值与要删除（更新）的基本关系的主码值相对应时，才可以删除（更新）该行（的主码），否则系统拒绝此删除操作  
    - CASCADE: 将依赖关系中所有外码值与基本关系中要删除的主码值所对应的行一起删除（将依赖关系中所有与基本关系中要修改的主码值所对应的外码值一起修改为新值）  
    - SET NULL: 删除（更新）基本关系中的行时，将依赖关系中与基本关系中被删（更新）主码值相对应的外码值置为空值  

## assertion

很多数据库不支持断言，以及带子查询的check，因为它们没有明确的触发条件，需要频繁检查，开销很大。

## 延迟约束

解决相互参照的表中无法插入数据的问题。比如 A 以 B 的外键约束，B 以 A 的外键约束，如果 A 表中没有数据，B 表中也无法插入数据。
