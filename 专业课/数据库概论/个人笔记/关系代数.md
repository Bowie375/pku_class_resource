# 关系代数运算
---

## 基本关系代数运算

### 选择运算

在关系中选择满⾜给定条件的元组。(⾏⻆度)即

```math
\sigma_F(R) = \{t | t \in R \land F(t) = 1\}
```

其中 $F$ 为选择条件。

**NOTE:** 不同顺序的选择操作结果相同但是效率不同。这取决于数据分布和索引配置。

### 投影运算

从关系中取出若⼲列组成新的关系(从列的⻆度)即

```math
\prod_A(R)=\{t[A]|t\in R\},A\subseteq R
```

投影的结果中要去掉相同的⾏

### 更名运算

将关系 $R$ 更名为 $S$

```math
\rho_S(R)=\{t[S/A]|t\in R\}, A\subseteq R
```

其中 $S/A$ 表⽰ $A$ 列的新名称。

### 并运算

所有⾄少出现在两个关系之⼀的元组集合,即

```math
R \cup S = \{t | (t \in R \lor t \in S)\}
```

要求

- $R$ 和 $S$ 必须是同元的,其属性数⽬必须相同
- 对 $\forall i$, $R$ 的第 $i$ 个属性和 $S$ 的第 $i$ 个属性的域必须相同

### 差运算

所有只出现在⼀个关系⽽不在另外⼀个关系中的元组集合,即

```math
R-S=\{t|(t\in R\land t\notin S)\}
```

要求 R 和 S 必须是相容的。

### 笛卡尔积

⽤来进⾏跨表的查询。定义元组的连串为 $\hat{rs} = (r_1,\cdots, r_n, s_1,\cdots, s_m)$, 其中 $r=(r_1, \cdots, r_n)$, $s=(s_1, \cdots, s_m)$。关系的笛卡尔积即为:

```math
R\times S = \{\hat{rs} |(r\in R \land s\in S)\}
```

## 扩展关系代数运算

### 交运算

所有同时出现在两个关系中的元组集合,即

```math
R \cap S = \{t | (t \in R \land t \in S)\}
```

要求 R 和 S 必须是相容的。交运算可以通过差运算来重写:

```math
R \cap S = R - (R - S)
```

### $\theta$ 连接

从两个关系的广义笛卡儿积中选取给定属性间满足一定条件的元组,即

```math
R\bowtie_{A \theta B}S=\{\hat{rs}|(r\in R\wedge s\in S\wedge r[A] \theta s[B]\}
```

其中 A 和 B 为属性的集合。

### 自然连接

从两个关系的广义笛卡儿积中选取在相同属性列B上取值相等的元组,并去掉重复的列,即

```math
R \bowtie S = \{\hat{rs}[\bar{B}] | (r \in R \land s \in S \land r[B] = s[B])\}
```

#### 属性

1. 自然连接中相等的分量必须是相同的属性组,并且要在结果中去掉重复的属性,而 $\theta$ 连接中则不必。
2. 自然连接有时会因为失配导致信息缺失

### 外连接

为避免自然连接时因失配而发生的信息丢失,可以假定往参与连接的一方表中附加一个取值全为空值的行,它和参与连接的另一方表中的任何一个未匹配 上的元组都能匹配,称之为外连接

- 左外连接: 自然连接 + 左侧表补空值行
- 右外连接: 自然连接 + 右侧表补空值行
- 全外连接: 自然连接 + 左右侧表补空值行

### 半连接

在 R 中能参与和 S 自然连接的行构成 R 半连接 S

### 外部并

将 R 和 S 在某一属性 B 上相同的行合并成一行

- 一般用于信息集成,将子实体集合并为父实体集
- 实体识别是判别两个子实体是否对应同一个实体

### 象集 (Image Set)

关系 R(X,Z), X, Z 是属性集, x 是 X 上的取值, 定义 x 在 R 中的象集为

```math
Z_x = \{t[Z] | t \in R \land t[X] = x\}
```

• 等价于选择加投影,即先选择 R 中 X 取值为 x 的元组,再投影出 Z 列

### 除法

问题:如何求得选修了全部课程的学生?

- 思路一: 判断每个学生的课程象集是否包含了整个课程集合
  - $ \mathsf{SC} = \{\mathsf{name}, \, \mathsf{classname}\}, \, \mathsf{C} = \{\mathsf{classname}\}$
  - $ \{u | r \in SC \land u = r[name] \land C \subseteq classname_u\}$
- 思考二: 判断学生与课程集合构成的笛卡尔积是否完全包含在选课集合中
  - $\{u|u \in \prod_{name}(SC) \land \forall v \in C(\{u,v\} \in SC)\}$
- 除法的本能: 所有,全部,任意
  - 定义表达式
    - $R(X,Y) \div S(Y) = \{x | r \in R \land x = r[X] \land Y_x \supseteq S\}$
    - $R(X,Y) \div S(Y) = \{u|u \in \prod_X (R) \land \forall v \in S(\{u,v\} \in R)\}$
  - 计算表达式:
    - $R(X,Y) \div S(Y) = \prod_X (R) - \prod_X (\prod_X (R) \times \prod_Y (S) - R)$

#### 实例

考虑问题:SC={scno, cno, grade} ,求选修了所有课程的学⽣

- ⽅案⼀: $\prod_{sno,cno}(SC \div \prod_{cno}(C))$
  - 正确
- ⽅案⼆: $\prod_{sno}(SC \div \prod_{cno}(C))$
  - 错误,求解了选修了全部课程并且成绩都相同的学⽣XUESHE

### 赋值运算

⽤左箭头($\leftarrow$)表⽰,将 R 中的元组 t 赋值给 S 中的元组 s,即

```math
s[A] \leftarrow t[A]
```

其中 A 为属性的集合。

### ⼴义投影

在投影列表中使⽤算术表达式来对投影进⾏扩展,即

```math
\prod_{F_1,F_2,\cdots,F_n}(E)
```

其中 $F_i$ 为算术表达式

类似于没有左值的赋值运算,可以⽤来对⼀个表进⾏更新

### 数据库修改

- 插⼊(insert):使⽤集合并运算来插⼊元组 
- 删除(delete):使⽤集合差运算来删除元组
- 更新 (update) :使⽤⼴义投影来更新元组,再进⾏赋值
